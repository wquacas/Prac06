## Часть 1. Информация о процессоре через WMI

Прогноз:
4 физ. ядра
8 логических процессоров

Наблюдение: прогноз совпали с результатом. Названия совпадают и количество тоже.

Environment.ProcessorCount показывает только итоговое количество логических процессоров.

Это происходит благодаря технологии Hyper-Threading. Она позволяет одному физическому ядру обрабатывать несколько потоков одновременно.
